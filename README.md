# 06-shiftboard（交班台）

交班台 — 班次责任与在途批次交接：班次登记 → 在途批次归属 → 交班互斥办理 → 交班前后对账。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓贴源/明细/汇总分层。  
**也不是** OA 考勤排班后台、电商订单、报表 CSV 看板。

## 启动

本地开发：

```bash
# 后端
cd backend
pip install -r requirements.txt
set DATA_DIR=%CD%\data
set FIXTURES_DIR=%CD%\..\fixtures
uvicorn app.main:app --host 127.0.0.1 --port 10600

# 前端
cd frontend
npm install
npm run dev
```

| 入口 | 地址 |
| --- | --- |
| 前端 | http://127.0.0.1:5600 |
| 接口 | http://127.0.0.1:10600 |

## 主链

登记班次与值班人 → 配置班次在途上限 → 在途批次归属当前班次 → 发起交班（全仓同时仅一单进行中）→ 完成前同事务容量预检（超限整单拒绝、零过户）→ 完成交班整批过户 → 交班对账报告与清单/批次同源

## 容量闸门

- 班次可配置在途容量上限（正整数）：`PUT /api/shifts/{id}/capacity`，班次页可直接改。
- 完成交班前必须预检：接班方当前在途 + 本单将过户键数 ≤ 上限，超限则整单拒绝、零过户，交班单记 `已拒绝` 并落原因。
- 裁决依据固化在 `capacity_prechecks` 表（按交班单 id：当前在途/清单数/上限/差值/裁决/原因），`GET /api/handovers/{id}/precheck` 可查；进行中单据返回实时预览。
- 预检与过户在同一事务（`BEGIN IMMEDIATE` 先锁写再数在途），过户后复核归属与上限，异常即整单回滚到完成前归属，禁止部分过户。
- 在途数一律从批次表同源派生，交班服务不另起容量计数器。

## 界面约定

页面文案全部中文；入口：总览 / 班次 / 在途批次 / 交班办理 / 交班记录 / 交班对账。
